# Awesome Claude terminal

*Unofficial community list for Claude Code in the terminal. Not affiliated with Anthropic. All trademarks belong to their owners.*

A curated list for anyone searching claude terminal, which in practice means Claude Code, Anthropic's tool for working with Claude from the command line. Every link below is a page from Anthropic's Claude Code documentation or one of the account pages it links to, grouped by what you are trying to do: install, configure, extend, or use it somewhere other than a terminal.

> Just need a site or an Expo app built from a prompt, no terminal involved? [Try Begin.sh - turn a prompt or a URL into a downloadable static site or Expo app](https://begin.sh?utm_source=github&utm_medium=ugc&utm_campaign=awesome-claude-terminal&utm_content=readme-top&utm_term=tier-r). Download the zip; no hosting, backend or auth.
